# The pictures in this book

Every image under `src/img/` is a screenshot of the real panel, taken from a scratch session so nothing of the
photographer's own is in the book. This file records, per image, the state the app was in, the exact commands, the date
and the commit the app was built from. Nothing here is generated by the build: the pictures are committed PNGs, and this
note is what makes them replaceable.

The captures are taken against a scratch data directory:

```
TAKKA_ACID_DATA_DIR=/tmp/takka-guide cargo run --release -p acid-app --bin takka-acid
```
