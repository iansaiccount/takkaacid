# The computer keyboard

The keyboard on your desk is both an **instrument** and an **editor**, and which one it is depends on what is held down. It
is worth ten minutes of practice, because a line typed at the keyboard is quicker to make than a line clicked into a step
row.

## As an instrument

```
A W S E D F T G Y H U J K
```

C, C#, D, D#, E, F, F#, G, G#, A, A#, B, C — a chromatic scale on the home row, the same layout most sequencers and DAWs
use. `Z` and `X` move the octave down and up, between two octaves down and two up.

A held key keeps the note sounding; the gate closes when every mapped key is up. There is one voice, so a computer key and
a MIDI keyboard play the same oscillator and the last one pressed wins. A key released while a MIDI note is sounding ends
that note too — one voice, one gate, no exceptions.

What you hear when you play a key is the same pitch that key would write into a step, so auditioning and editing can never
disagree about which note is which.

## As an editor

Hold **`shift`**, or turn **`STEP`** on, and the same letters stop playing and start writing. The note goes into the
selected step instead of the voice.

- With `shift` down the selection stays put: good for correcting one step.
- With `STEP` on, a key **down** writes and the key **up** walks the selection on by one: good for typing a phrase left to
  right.

The rest of the editing keys, in the order you will meet them:

| Key | What it does |
|---|---|
| `left` / `right` | move the selection one step |
| `shift+left` / `shift+right` | previous / next pattern (`11-the-bank`) |
| `shift+up` / `shift+down` | note up or down a step |
| `enter` | note on or off |
| `backspace` | empty the step to a rest (while editing) |
| `space` | start or stop, same as `RUN` / `STOP` |
| `up` / `down` | tempo, one BPM |
| `F1` or `shift+?` | the help card |
| `F2` | the settings card |
| `escape` | close a card, or give up on a `LEARN` |

## Why one voice is not a limitation

This is a bass machine: one line, one oscillator, one filter. The keyboard being monophonic is the instrument being honest
about what it is — and it is why pressing a key while a note is playing does the expected thing, rather than stacking
notes the machine would have to drop.

If you want chords, you want another instrument. If you want a line that talks, this is the one, and the keyboard is the
fastest way to write it.
